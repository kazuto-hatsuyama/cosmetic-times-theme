## 要件定義（実装用）

### 誰の課題か
- Cosmetic Timesの運営者（配送業務・データ連携担当）
- カートページで配送設定を行うエンド顧客（会員・非会員問わず）
- 基幹DB（OM_OrderDT）への連携処理を実装するデータ系チーム

### 現状
- Shopify移行後、配送希望日・お届け希望時間・宅配ボックス利用の設定機能が未実装
- カートアイコン押下でカートドロワー（settings.cart_type=drawer）が開く仕様になっており、配送設定をカートページで入力させる導線がない
- 旧サイト（cosmetic-times.com）では定休日が土日・祝日、営業時間10:00-17:00で、営業日カレンダー画面（休業日/出荷のみ休業/お問い合わせのみ休業の3区分）を運用側で随時更新し、配送可能日数の変動（年末年始等）に対応している
- 旧サイトの基幹DB項目は OM_OrderDT.AppointDate（お届け希望日）／AppointTime（お届け希望時間、コード値 00=指定しない/08=午前中/12=12-14時/14=14-16時/16=16-18時/18=18-20時/19=19-21時）／DeliveryBoxFlg（宅配ボックス利用、コード値 00=利用する/01=利用しない）

### 変更後どうなるか
- カートアイコン押下時、ドロワーではなく/cartへ遷移する（settings.cart_typeをdrawerからpageへ変更。config/settings_data.jsonはライブ自動デプロイで同期されないため、変更後は個別pushが必要）
- カートドロワー等からカートページを経由せず直接チェックアウトへ進める導線がないか確認する（調査済み: PDPのaccelerated-checkoutブロック(Buy it Now等)およびカートページ内の高速チェックアウトボタンがこれに該当するが、配送設定は任意項目とする方針のため、これらのボタン自体は変更しない）
- カートページに「お届け希望日」「お届け希望時間」「宅配ボックス利用」の入力項目を追加する（いずれも入力必須にはせず任意項目とする）
- お届け希望日は、テーマ設定（管理画面）で調整可能な「最短リード営業日数（デフォルト7営業日）」「配送不可日リスト（YYYY-MM-DD形式、複数行）」に基づき、土日および配送不可日を除外した営業日ベースで選択可能な最短日を算出する。選択可能な上限日数もテーマ設定で調整可能にする
- 入力値はShopifyカート属性として保持する: delivery_date（お届け希望日、YYYY-MM-DD形式の文字列）／delivery_time（お届け希望時間、コード値 00/08/12/14/16/18/19）／delivery_box（宅配ボックス利用、コード値 00=利用する/01=利用しない）。値は基幹DB（OM_OrderDT.AppointDate/AppointTime/DeliveryBoxFlg）とのデータ連携を想定し、コード値そのままをカート属性値として保持する（ラベル変換はしない）
- チェックアウト画面自体はカスタマイズせず、Shopify標準のカート属性の仕組みにより注文確定後も注文側の属性として値を取得可能な状態にする
- 既存のランク割引・ポイント利用・クーポン利用機能（cart-summary.liquid, cart-points.js, cart-discount.js等）の挙動（小計・割引額・ポイント上限計算等）に変化がないことを確認する
- 実装後、カートアイコン→カートページ→配送条件設定→チェックアウトの一連の動作を実機で確認する
- テーマをデプロイした場合、Judge.me Reviewsウィジェットの再設置が必要（既知の運用事項）なため、デプロイ後にレビュー表示も確認する

### 受け入れ基準
- カートアイコンを押下すると、ドロワーが開かず/cartページに遷移する
- カートページの配送設定UIで日付・時間・宅配ボックスを選択すると、/cart/update.js経由でcart.attributesに delivery_date/delivery_time/delivery_box が指定のコード値でセットされることが確認できる
- お届け希望日inputの選択可能最小日が、テーマ設定のリード営業日数・配送不可日リストを反映して算出されている（土日・登録済み配送不可日が除外されている）
- テーマ設定のリード営業日数・配送不可日リストを変更すると、選択可能な最短日がコード修正なしに変わることが確認できる
- チェックアウトを完了した注文で、上記3項目の値が注文属性として確認できる
- ランク割引・ポイント利用・クーポン適用のいずれも、配送設定追加前と同じ挙動・計算結果になる（デグレなし）
- デプロイ後、Judge.meレビューウィジェットが表示されている（再設置後）

## 対象外
- マイページ等での配送設定の事後編集・変更
- 電話・郵便注文フローへの対応
- 宅配ボックス利用可否に関する住所側のバリデーション
- チェックアウト画面（Checkout UI Extensions等）のカスタマイズ

## 未決事項
- 配送不可日リストの実際の値（祝日・年末年始日など具体的な日付）は運用開始前に運営者側で入力してもらう想定。初期値は空またはサンプル値のみで実装する
